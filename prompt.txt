# Project: Swedish Learning App

Act as a senior mobile application architect, experienced React Native developer, UI/UX designer, and Swedish language-learning specialist.

I want you to design and build a beautiful iOS application that helps me learn Swedish through illustrated stories, interactive vocabulary learning, and SFI-style language exercises.

I am developing on a Linux laptop using Claude Code. Therefore, choose technologies and development workflows that work well on Linux.

Use React Native, Expo, and TypeScript unless you have a compelling technical reason to choose something else.

The application should be designed primarily for iPhone.

This is a personal learning application, but the architecture should be clean, extensible, and suitable for adding more content and features later.

Do not build a generic language-learning app. The main experience should feel like reading a beautifully illustrated children's book while gradually learning Swedish.

---

# 1. Main Concept

The application has four main learning areas:

1. Read illustrated Swedish stories.
2. Learn and collect new Swedish vocabulary while reading.
3. Practice Swedish grammar and vocabulary through exercises.
4. Test knowledge of Swedish history, culture, and facts learned from the stories.

The initial application should contain three complete Swedish stories.

However, I must be able to import additional stories in the future without changing the application code.

The application should support progressive learning from very easy Swedish to intermediate Swedish.

Use SFI (Svenska för invandrare) as the general educational reference, especially the progression from beginner to intermediate levels.

Aim for a progression roughly covering:
- Very beginner: A1
- Beginner: A1-A2
- Elementary: A2
- Intermediate: B1

The application should not overwhelm beginners.

# 4. Illustrated Story Reading Experience

This is the heart of the application.

I want to read stories in Swedish, presented as individual illustrated pages.

A story should contain at least 10 pages. Preferably 10–20 pages depending on the story.

Each page should contain:

- One illustration or graphic when appropriate.
- A short Swedish text.
- A comfortable font size.
- Clear paragraph spacing.
- Page number.
- Previous and Next navigation.

The text should not be excessively long.

Think about the layout of a children's illustrated book.

For example:

Page 1:
A large illustration occupying approximately 50% of the screen.

Below it:
A Swedish paragraph consisting of approximately 50–100 words.

The exact layout should adapt to the content and device size.

Some pages can have:
- Large illustrations with short text.
- Smaller illustrations alongside text.
- Maps.
- Historical timelines.
- Character illustrations.
- Cultural objects.
- Simple diagrams.

Do not force every page to use the same layout.

### Reading navigation

Support:

- Swipe left/right to change pages.
- Previous/Next buttons.
- Chapter navigation.
- Reading progress indicator.
- Bookmarking a page.
- Resume reading from the last position.

Avoid making the user scroll through a massive article.

Prefer a paginated reading experience.

### Text interaction: Long-press dictionary

This is a critical feature.

When I encounter a Swedish word I don't understand:

1. I long-press the word.
2. The application identifies the selected word.
3. A beautiful tooltip or popover appears.
4. The tooltip displays the English translation.
5. It also displays the base/dictionary form of the word when applicable.
6. Optionally display a short explanation or example sentence.
7. Provide a button to save the word to My Vocabulary.

Example:

Swedish sentence:

"Flickan gick långsamt genom den gamla skogen."

If I long-press "skogen", show:

Swedish word: skogen

Base form: skog

English: the forest

Word type: Noun

Definite form: skogen

Plural: skogar

Example:
"Skogen är mycket vacker."

Actions:
- Add to My Words
- Close

Another example:

Selected word: gick

Base form: gå

English: went

Verb form: Preteritum

Present: går

Past: gick

Supine: gått

### Important technical requirement

Investigate the best way to implement reliable word-level long-press interaction in React Native.

The interaction should work with Swedish characters:
å, ä, ö.

Avoid a solution that makes normal text selection or reading uncomfortable.

If necessary, implement a custom text-rendering component that supports individual word interaction.

The experience should work consistently across different screen sizes.

### Vocabulary translation

The initial application should work offline.

Therefore, do not require a remote translation API for every word interaction.

Design a local vocabulary dictionary and a translation-resolution architecture.

Possible approaches:
- A bundled Swedish-English dictionary.
- A local dictionary database.
- An optional future AI translation provider.

If a word is not found, show an appropriate fallback rather than inventing a translation.

# 6. Swedish Grammar Practice

Create a separate grammar-learning section.

The exercises should follow concepts commonly taught in SFI.

Organize exercises by topic and difficulty.

Initially, implement the following topics:

### A. Nouns

- En and ett.
- Indefinite and definite forms.
- Singular and plural.
- Plural endings:
  - -or
  - -ar
  - -er
  - -n
  - No ending change.
- Definite plural forms.
- Common noun exceptions.

Example:

En flicka → flickan → flickor → flickorna

Ett hus → huset → hus → husen

### B. Verbs

Teach:
- Infinitiv.
- Presens.
- Preteritum.
- Supinum.
- Future tense.
- Regular and irregular verbs.

Example:

Att gå:
- Presens: går
- Preteritum: gick
- Supinum: gått

Att prata:
- Infinitiv: prata
- Presens: pratar
- Preteritum: pratade
- Supinum: pratat

### C. Adjectives

Teach:
- Adjective agreement.
- En words.
- Ett words.
- Plural forms.
- Definite forms.
- Comparative.
- Superlative.

Example:

Stor:
- En stor bil.
- Ett stort hus.
- Stora hus.

### D. Pronouns

Teach:
- Personal pronouns.
- Possessive pronouns.
- Object pronouns.
- Reflexive pronouns.
- Demonstrative pronouns.

### E. Sentence Structure

Teach:
- Basic Swedish sentence structure.
- Subject and verb.
- Main clauses.
- Word order.
- V2 rule.
- Questions.
- Negation.
- Adverb placement.

### F. Prepositions

Teach common prepositions:
- I
- På
- Till
- Från
- Med
- För
- Av
- Hos
- Under
- Över

### G. Other important SFI topics

Include:
- Question words.
- Conjunctions.
- Time expressions.
- Adverbs.
- Common expressions.
- Modal verbs.
- Imperative.

### Exercise experience

Every grammar topic should have:

1. A short explanation in simple English.
2. Swedish examples.
3. A practice section.
4. Immediate feedback.
5. An explanation of why the answer is correct or incorrect.

Use varied exercises:
- Multiple choice.
- Fill in the blank.
- Sentence construction.
- Matching.
- Choosing the correct grammatical form.
- Correcting incorrect sentences.

Do not simply show the correct answer.

Explain the grammar behind it.

Start with relatively easy exercises and gradually increase difficulty.

5. Define the database schema.
